Maths Topic 2.3 - Functions

What Is A Function?

A function is a relationship that maps each value of a set of inputs to a single output. The notation \(f(x)\) represents a function of x.
The set of possible inouts is called the domain, the set of possible outputs is called the range, the roots are values of x where \(f(x)=0\)
See Maths Topic 2.1 - Solving Quadratic Equations for finding the roots of a quadratic function, and Maths Topic 2.4 - Quadratic Graphs for the graph of one. The programming equivalent of a function is in Computer Science Topic 56 - Subroutines and recursion.
Transformations of functions are covered in Maths Topic 4.5 - Translating Graphs, Maths Topic 4.6 - Stretching Graphs and Maths Topic 4.7 - Transforming Functions, and finding the roots of higher order polynomials is in Maths Topic 7.3 - The Factor Theorem.
