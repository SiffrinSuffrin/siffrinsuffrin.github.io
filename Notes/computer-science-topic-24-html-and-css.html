Computer Science Topic 24 - HTML And CSS

Hypertext Markup Language (HTML)

HTML is the language web pages are written in. It describes the content and structure of a web page so the browser can render it for a viewer. Cascading Style Sheets (CSS) dictate the style and formatting.

HTML Tags

HTML is made up of tags written in angle brackets, in opening and closing pairs. A standard web page is formed of two sections, a <head> and a <body>, the header being the title and any scripts used, and the body being the main content of the page.
Common tags include:

  • <html> - all code within is defined as HTML
  • <body> - defines the content in the main area
  • <head> - defines the window heading
  • <title> - defines the text that appears in the window heading
  • <h1>, <h2>, <h3> - heading styles in decreasing sizes.
  • <p> - for paragraphs
  • <img> - self closing image tag
  • <a> - anchor, shows a hyperlink
  • <ol>/<ul> - defines an ordered/unordered list
  • <li> - list item for the above

<div>

This HTML tag divides the page into areas, so CSS can be used on them separately

CSS Script

CSS is a style sheet language that describes layout and style of existing HTML elements.

Embedded, Inline, And External CSS

CSS can be inserted directly into the HTML document head using style tags, or into the line that requires the change in CSS. Either keep the CSS in the HTML, and allow one-off changes. The best way however, is to provide declarations in an external style sheet, using the link tag.

Identifiers And Classes

Identifiers and class selectors are the points in HTML that styles are applied onto, by adding the id or class name into the html element. Identifiers are used once, and shown with a #. Classes are used multiple times, and defined with a full stop.

A web page is text stored as character codes, see Computer Science Topic 29 - ASCII and Unicode, and colours in CSS are commonly written in hexadecimal (Computer Science Topic 28 - Primitive Data Types, Binary and Hexadecimal). HTML and CSS are written in a text editor or an IDE (Computer Science Topic 57 - Use Of An IDE), and the rendered page is shown on the output devices in Computer Science Topic 5 - Output Devices.
