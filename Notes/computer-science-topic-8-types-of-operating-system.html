Computer Science Topic 8 - Types Of Operating System

Distributed Operating Systems

A distributed operating system is where every job is split into several tasks, across several computers, coordinated by the operating system in such a way it appears to the user as a single, larger machine. Intranets commonly use this to cluster servers, sharing memory and tasks.

A Multi-tasking System

A multitasking operating system runs on a standalone computer, and can run many jobs simultaneously, switching between them.

A Multi-user, Multi-tasking System

Time sharing systems are multi-user, multi-tasking systems. A single powerful mainframe or supercomputer is connected to dozens of terminals. Each user gets a slice of processor time, as according to a scheduling algorithm.

Operating Systems Used By Mobile Phones

A mobile phone is a multi-tasking computer with its own operating system. Operating systems used on smartphones/tablets/etc are termed mobile operating systems. They combine a PC's operating system features with their own special features, like touchscreen support, or cellular communications. Most mobile operating systems are tied to specific hardware. Most actually have two systems, a main operating system running the main ui, and a second low level real time operating system running the radio and other hardware. These have a range of vulnerabilities allowing others to gain control over the device (and non mobile OSes too... like Intel ME/AMD PSP).

Embedded Operating Systems

An embedded operating system is an extremely simple operating system for embedded devices, burnt directly into ROM. It has a minimal user interface, sensor inputs, control device outputs, a limited amount of RAM, and no permanent storage management.

Real-time Operating System

Real time operating systems are systems where the main goal is to respond as quickly as possible, processing many inputs. It should have fail safes and redundancy.

BIOS (Basic Input Output System)

BIOS is the program stored in EPROM (Erasable Programmable Read Only Memory) that gets your computer started after you turn it on. The fundamental part is to initialise and test the system hardware. Historically, it was used to provide an abstraction layer to interact with I/O devices, but that has not been used in modern computers for many years.

Device Drivers

A device driver is a computer program that provides a software interface to a particular hardware device, enabling operating systems to access new hardware functions without knowing the precise details of the hardware being used. The OS can do this automatically if it already has a driver for it, or can download it from the internet. Drivers are hardware dependent and operating system specific. A driver typically communicates with the device via the system bus or other communication subsystem to which the hardware connects. When a calling program invokes a routine in the driver, the driver issues commands to the device, which then returns data to the calling program.

Virtual Machine

A virtual machine can be described as software emulating the function of another machine, including executing intermediate code or running an operating system within another to emulate different hardware.
