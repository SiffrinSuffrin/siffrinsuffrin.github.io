Computer Science Topic 30 - Binary Arithmetic

Addition

0 + 0 = 0
0 + 1 = 1
1 + 1 = 0 carry 1
1 + 1 + 1 = 1 carry 1
(column by column)

Signing, Negatives, And Subtraction

Sign/Magnitude representation replaces the highest bit with a bit indicating whether the number is negative or not (1 for negative, 0 for positive)
Easy to understand, but hard to implement computationally

Two's Complement representation has the highest bit become a negative equivalent, ie bit 8 becomes -128, or bit 3 becomes -4 (work out opposite polarity, flip all bits, add 1)
Harder to understand, extremely easy to compute with. It is also used for the exponent in Computer Science Topic 31 - Floating Point Arithmetic.

To subtract, negate the number you wish to subtract, then simply add it to the other number.

Example work

-01111001 -> 10000111
10110011 + 10000111 -> 100111010 -> 00111010
11010111 + 11011100 -> 110110011
