Computer Science Topic 6 - Storage Devices

The Need For Secondary Storage

A computer's primary store is RAM. Unlike RAM, secondary storage is not directly accessible, and has slower access speeds. However, it retains its contents after power is lost. This is any SSD, HDD, or optical media.

How Storage Devices Store Data

Each use a different method, but all use different (toggle state) based methods.

Hard Disk

A hard disk uses rotating platters, magnetically coated. Ferrous particles, north or south polarised, represent 0 and 1. The disk forms "tracks" in concentric circles, which are subdivided into sectors. The platters spin at ~10,000RPM. A drive head floats just above the surface of the disk, reading from or writing to areas of the disk as they pass under it.

Optical Disk

Optical disks come in: read only, recordable (write once), and rewritable (write multiple). The disk works by using a laser to change the reflectivity of the surface. A low power laser can then read it, by shining and then having a sensor measure the returned light. A read-only disk has physical pits on the disk instead. Unlike a hard disk, there is one track, forming a tight spiral. Cheap to make, easy to send through post.

Solid State Disk

Instead of a spinning disk, a series of NAND-based memory chips store data, with a controller managing pages and blocks to memory. They work by trapping electrons in a floating gate, no charge being a 1, and some charge being a 0. Data is stored in pages (~4kib), grouped into larger blocks (for example, 512kib). Writing data requires an entire block to be written at once, given that old data must first be erased before data can be written. A separate mirrored block is created with the new data. The old block is then marked stale, and erased later. Although they are more expensive, they are faster, lighter, and silent.

RAM And ROM

RAM (Random Access Memory) stores programs and data that are currently in use, and is lost when the computer turns off.
ROM is used to hold information that should be PERMANENTLY accessible in memory. Examples include the BIOS/bootstrap loader, or the main program of an embedded system.

Virtual Storage

Virtual storage/memory is where a hard disk is used as an extension of memory, when it is too small to hold everything you're doing at once. On Linux, this is commonly referred to as Swap, or a Page File on Bindoj.
