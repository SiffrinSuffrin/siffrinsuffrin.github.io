Computer Science Topic 3 - Types Of Processor

Memory And The Stored Program Concept

Stored program concept: machine code instructions are fetched and executed serially by a processor that performs arithmetic and logical operations.

Von Neumann

Same data/address bus transfers instructions and data which is stored in the same memory. Used in nearly every conventional processor. See Computer Science Topic 1 - Processor Components for buses and registers.

Harvard

Separate data/address bus, separate memory for instructions and data. Used primarily in Digital Signal Processing and Embedded Systems.

Contemporary Processor Architectures

Modern CPUs use both, having separate data and instruction cache but a shared main memory. Cache is covered in Computer Science Topic 2 - Processor Performance.

Complex Instruction Set Computers (CISC)

A large instruction set, with instructions carrying out complex tasks over multiple clock cycles. Distinguishing feature is combined load/store and operation. Compiler has little work to do when compiling for a CISC, as it already implements most features in hardware. Takes less RAM, as it is shorter code. Many specialised instructions, with less than ~20% being used regularly.

Reduced Instruction Set Computers (RISC)

Small number of single simple instructions, each taking 1 cycle. Simple hardware, complex compilation, easy pipelining (Computer Science Topic 2 - Processor Performance), more RAM needed for longer programs.

Coprocessor Systems

A co-processor is a special dedicated processor that augments the main CPU, by performing a special dedicated task, like floating point arithmetic, or graphics operations. See Computer Science Topic 31 - Floating Point Arithmetic for floating point.

Multicore/Parallel Systems

Multicore CPUs can schedule tasks across each core, executing them in parallel, allowing for vast speedups (see Computer Science Topic 2 - Processor Performance for the effect on performance).

GPU

A GPU (graphics processing unit) is a dedicated form of co-processor for graphics, consisting of several thousand highly parallel cores, to process many parts of an image at once.
See Computer Science Topic 6 - Storage Devices for RAM and ROM, which hold the programs and data, and for secondary storage. The monitors and projectors the GPU sends images to are in Computer Science Topic 5 - Output Devices. The embedded systems that often use the Harvard architecture run the simple embedded operating systems in Computer Science Topic 8 - Types Of Operating System.
