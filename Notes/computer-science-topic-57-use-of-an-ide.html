Computer Science Topic 57 - Use Of An IDE

Facilities Of An IDE

An IDE is a dedicated text editor for writing code. It provides facilities such as debugging, executing, and saving programs. HTML and CSS are written in a text editor or IDE like this, see Computer Science Topic 24 - HTML And CSS.

Common Debugging Options:

  • Step In - Execute one line, stepping into a function if it calls one
  • Step Over - Executes the entire next line of code, including executing an entire function if it is one.
  • Step Out - Executes remainder of current function
  • Run To Cursor - Executes until the line where the cursor is
  • Breakpoints - Execute normally, then stop at marked lines.
    Stepping in and out is most useful with subroutines (Computer Science Topic 56 - Subroutines and recursion), and breakpoints with loops (Computer Science Topic 55 - Iteration). Methods in OOP are subroutines too, so stepping into one lets you watch an object's attributes change, see Computer Science Topic 58 - Use Of Object Oriented Techniques.
