Computer Science Topic 1 - Processor Components

The CPU

Semiconductors are the basis of the components inside a processor, see Physics Topic 4.1.3 - Electron Drift Velocity.
The CPU consists of a number of different components to execute instructions, including the following:

Control Unit

The control unit controls and coordinates the activities of the cpu directing the flow of data between the cpu and other devices. it accepts the next instruction, decodes it into several steps (micro-instructions), and runs them.

Buses

A bus is a set of wire connecting any components of a computer. It's not THAT complicated people. There's three buses, address, data, and control bus, collectively known as the system bus. Device drivers communicate with hardware over the system bus, see Computer Science Topic 8 - Types Of Operating System.

Arithmetic Logic Unit

It does maths. What else do you want me to say here. See Computer Science Topic 30 - Binary Arithmetic and Computer Science Topic 32 - Bitwise Manipulation And Masks for the operations it carries out.

Registers

Special local memory within the cpu core, for performing operations on. The fastest possible accessible memory location. The operating system saves these registers to the stack when an interrupt occurs, see Computer Science Topic 7 - Functions Of An Operating System.

  • Program Counter - Next executable address
  • Current Instruction Register - Current instruction
  • Memory Address Register - Address of memory being read/written
  • Memory Data Register - Memory buffer

FDE

Fetch

  • PC copied to MAR
  • Data at MAR address copied to MDR
  • MDR copied to CIR
    Decode
  • CIR decoded into opcode/operand
  • Opcode decoded into microinstructions
    Execute
  • Microinstructions/Opcode carried out on operand
