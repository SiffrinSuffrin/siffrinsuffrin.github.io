Computer Science Topic 33 - Records

1D Arrays

An array is a finite (specific number of items), ordered (there is a first second third etc etc) set of items of the same type.

2D Arrays

An array can have more dimensions, by nesting arrays within one another. A 2D array is similar to a table/spreadsheet, where a coordinate is used to address the specific item.

3D Arrays

Array. 3 arrays in each other. Do I really need to explain this.

Tuples

A tuple is an ordered set of values of any type, and is immutable (unchangeable).

Records

A file/database consists of a number of records for a particular entity. A record contains a number of fields, the type of which defined by attributes, each holding one item of data. For example, where each row is a record:

attribute attribute attribute
record1 field field field
record2 field field field

(There are no records in python, but dictionaries (dict = {}) work similar enough)
See Computer Science Topic 28 - Primitive Data Types, Binary and Hexadecimal for the primitive data types the fields hold, and Computer Science Topic 58 - Use Of Object Oriented Techniques for how objects in OOP bundle data and operations together in a similar way.
Arrays are usually processed with loops, see Computer Science Topic 55 - Iteration. A coordinate pair such as \((x_1, y_1)\) in Maths Topic 5.4 - Length and Area is a tuple, and a 2D array addresses an item by a coordinate in a similar way. Files of records are kept on secondary storage (Computer Science Topic 6 - Storage Devices), and the operating system keeps a directory of where each file is, see backing store management in Computer Science Topic 7 - Functions Of An Operating System.
