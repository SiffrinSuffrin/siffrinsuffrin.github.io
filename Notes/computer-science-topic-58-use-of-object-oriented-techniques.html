Computer Science Topic 58 - Use Of Object Oriented Techniques

Procedural Programming

Procedural languages are usually programmed by writing a step by step series of instructions, and smaller modules.

Object-Oriented Programming

In OOP, everything is a collection of objects, which can represent anything. An OOP program is composed of a number of interacting objects, each of which is responsible for its own data and the operations on the data.

Object Attributes And Behaviours

Each object will have its own attributes (ie, describing properties, like a car has an attribute of its make).
An attribute has a "state", like a radio has a power state of "on" or "off".
An object has behaviours, the actions performed by an object.

Classes

A class is a template for an object, and describes the attributes and behaviours (methods) of an object. As a rule of thumb, an instance (an object made from a class) will have private variables, and public methods. This principle of information hiding is key in OOP.

Instantiation

A constructor is used to create objects in a class. Once the class and constructor have been defined, new objects can be created, this is called instantiation. For example, book1 = book("Book", "Computer Science", 35) would create a pointer (reference, giving a location) in the book1 variable to the memory location containing the object.

Sending Messages

Messages are getter or setters, getters being functions that return a value, setters being subroutines that set a value.

Encapsulation

An object encapsulates both its state and behaviours. All the data and methods of an object are wrapped up, so the attributes/behaviours of one object do not affect the others. This allows programmers to use methods from other classes without knowing how they work, and to write methods without being concerned about them being affected by other parts of the system. This is related to information hiding, in that the details of the object are hidden, so that other objects must use messages
to interact with that object's state. (Public V Private, __name stops interaction with data from outside a class, making it private, so it can only be accessed via its methods.)

Inheritance

Classes can inherit data and behaviour from a parent class (superclass, child is a subclass) the same way children inherit parent's characteristics. Classes inheriting other classes can be used to provide a number of different classes of the same type common default values for their attributes, and common methods. super().__init__() allows you to call your super's init function in Python.

When To Inherit

Use the rule of thumb: if X is a Y, inherit Y. Nothing's stopping you from going against this but it's bad practice and dumb, do not do this.

Polymorphism

Polymorphism is a programming language's ability to process objects differently based on class. This allows subclasses to override methods provided by their superclass, by providing the same name for a method as one of their superclasses.
