Computer Science Topic 32 - Bitwise Manipulation And Masks

Logical Shift Instructions

A logical shift instruction moves all the bits left or right. A logical shift right causes the least significant bit to go into the carry bit, and the highest bit to be replaced by a zero, ie
\(shiftR(10110001) = 01011000 (carry 1)\)
Shifting left works in the same way, but in reverse.
\(shiftL(10001110) = 00011100(carry 1)\)
This is equivalent to dividing (rshift) or multiplying (lshift) by \(2^n\) where n is the number of places to shift. See Maths Topic 1.1 - Index Laws for powers.

Arithmetic Shift

The exact same, but the sign bit is preserved (on a right shift it is copied into the gap, so the number keeps its sign). It's not rocket science people. You can use a combination of binary addition and shifts to multiply any two binary numbers (break one down to powers of twos, and one, ie \(9 × 5\) becomes \((1 × 5) + (8 × 5)\), which is \(5 + shiftL(5,3)\) (3, because \(2^3 = 8\))). This works because of Maths Topic 1.2 - Expanding Brackets.

Circular Shift

A circular shift has the carry bit read from and written to. In a circular right shift for example, the lsb becomes the carry bit as the carry bit becomes the msb. This is useful for shifting across multiple bytes.

Logical Instructions

Apply boolean algebra across multiple bits (see Computer Science Module 8 Index), write the binary numbers out on top of each other, then apply the boolean operation columnwise. The ALU carries these out (Computer Science Topic 1 - Processor Components).

Masking

ORing any binary number with a mask allows you to set selected bits to 1.
ANDing any binary number with a mask allows you to only keep the selected bits
XORing any binary number with a mask allows you to invert selected bits
See Computer Science Topic 28 - Primitive Data Types, Binary and Hexadecimal for binary and hexadecimal and Computer Science Topic 30 - Binary Arithmetic for binary arithmetic. The operators themselves are in Computer Science Topic 34 - Boolean Algebra.
