Computer Science Topic 7 - Functions Of An Operating System

What Is An Operating System?

An operating system is a program or set of programs that manage the operations of a computer for the user. It acts as a bridge between the user and the hardware, since a user cannot directly communicate to it. A small program in the BIOS called the loader starts the operating system, copying it from secondary storage to RAM.

Functions Of An OS

  • Memory management
  • Interrupt service routines
  • Processor scheduling
  • Backing store management
  • I/O management

Memory Management

An OS manages memory for the user, so they can use several programs simultaneously, and switch between them, as each area of memory for the program is loaded, or moved to the disk.

Paging And Segmentation

Paging is where memory is divided into fixed size pages of 4KB each, and a process may be held in several of these non-contiguous pages. A "Page Table" stores a link between the physical memory address and logical memory address.
Segmentation is the division of address space into variable length segments based on the program structure.

Virtual Memory

As more and more memory becomes used, pages of inactive jobs are moved onto disk to make room for the next job. If a large number of programs are loaded, a significant slowdown will occur due to the mismatch of memory and secondary storage.

Interrupt

An interrupt is a signal from software, hardware or clock to the CPU. A software interrupt occurs when a program needs to run an OS service, or it terminates. A hardware interrupt occurs when an I/O operation finishes, or an error occurs. Interrupts also occur to indicate it is the next process's turn.

Interrupt Service Routines

When an interrupt occurs, the current state of the CPU is passed to the system stack, and an Interrupt Service Routine is called. Each interrupt has its own routine. Some interrupts are higher priorities than others, and can interrupt an interrupt. Afterwards, the original values of the register are restored.

Processor Scheduling

Processor Scheduling is how the operating system allocates processor time to each application fairly and efficiently, to each core. This is what is meant by multitasking. The scheduler is the OS module making sure processor time is used efficiently, trying to:

  • Maximise throughput
  • Be fair to all users
  • Provide an acceptable response time
  • Ensure all resources are kept busy

Round Robin

Processes dispatched in a FIFO queue, with each being given a limited amount of CPU time (time slice/quantum), using an interrupt timer to change what is running. Some may be extended with a priority system, with higher priorities having more quantum.

First come first served

Self explanatory, jobs are run as they arrive

Shortest Remaining Time

The process with the shortest remaining time till completion is run next. This reduces the number of jobs waiting, and stops small jobs being stuck behind bigger ones. The downside is it requires estimation of time per job for each job.

Shortest Job First

Similar to the above, but for the shortest total time to run the entire job.

Multi Level Feedback Queues

This is designed to:

  • Prefer small jobs
  • Prefer I/O bound processes
  • Separate jobs into categories based on their needs
    The algorithm implements many queues, with jobs being able to move between queues based on the required processor time and the time they've been waiting (more use is moved to lower priority, longer wait is moved to higher priority). Since I/O is slower than processor speed, it is efficient to maximise the use, so bottlenecks do not occur when many jobs need it. The aim is to maximise processor use.

Backing Store Management

The operating system keeps a directory of where files are so they can be quickly accessed. It also needs to know where areas are free so new files can be placed there. A file management system comes with every OS, and enables a user to move, delete, and protect files.

Peripheral Management

The OS manages all I/O devices attached to the computer, moving data to and from buffers (spaces in memory to hold temporary I/O data, compensating for the speed difference) while it does other work, and communicating with any devices.
Peripheral management also covers the devices in Computer Science Topic 5 - Output Devices.
