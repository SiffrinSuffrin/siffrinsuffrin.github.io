Computer Science Topic 29 - ASCII and Unicode

Bits and Bytes

A bit is either a single 1 or 0. A byte is 8 bits.

Unit Nomenclature

1024 is referred to as a kilobyte, but is actually a kibibyte. A similar convention is used for all the other units, ie the decimal unit \(10 ^ {3x}\) is actually used to refer to the binary unit \(2 ^ {10x}\). (Maths Topic 1.1 - Index Laws).

The ASCII code

7 bits, forming 128 characters, allowing you to cover all the characters on a standard English keyboard. There is also an 8 bit version that adds 128 more common codes.

Unicode

By 1980 there were a number of different incompatible coding systems. As a result, the 16 bit unicode was introduced, allowing 64K different characters. Later, UTF-32 unicode was introduced, allowing a million characters. While this is good for interchanging data, it means there are now four bytes per character instead of two.
Storage capacities are measured in these units, see Computer Science Topic 6 - Storage Devices. Web pages are text stored with these character codes, see Computer Science Topic 24 - HTML And CSS.
