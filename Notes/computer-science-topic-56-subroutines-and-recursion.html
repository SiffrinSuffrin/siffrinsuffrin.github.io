Computer Science Topic 56 - Subroutines and recursion

Types Of Subroutine

A subroutine is a named block of code which performs a specific task within a program. High level languages support two types, "functions" and "procedures". In languages that discriminate between them, a function's result is assigned to a variable, a procedure is not.

Subroutine details

A subroutine takes in zero or more values, then returns zero or more pieces of data. Variables in the context of a subroutine cannot be accessed by the main program, but the main program's variables can be accessed by the subroutine.

Benefits

Modularity
Independent testing
Reuse in other projects
Easier to split work between programmers

Recursion

A subroutine is recursive if it calls itself, until it reaches a case where it does not need to, then unwinds. Every time a recursive call is made, variable values are pushed to the stack, so there can be high demands for storage space on the stack.
Recursion is an alternative to Computer Science Topic 55 - Iteration. Methods in OOP are subroutines attached to objects (Computer Science Topic 58 - Use Of Object Oriented Techniques). A factorial (Maths Topic 8.2 - Factorial Notation) is a classic recursive function, since \(n! = n × (n-1)!\), stopping at \(1! = 1\).
