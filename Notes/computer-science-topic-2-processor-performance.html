Computer Science Topic 2 - Processor Performance

Primary Factors

  • Clock speed
  • The number of cores
  • Amount of cache memory

Clock Speed

The system clock generates an alternating signal of 0 and 1s, used to synchronise the processor, at a speed of several billion Hz (GHz). Faster clock = more instructions per second.

Number Of Cores

Each core is its own CPU, allowing the computer to execute more instructions in parallel, given the software is correctly able to take full advantage of both processors

Amount And Type Of Cache Memory

Cache is a tiny, expensive, fast memory inside of the CPU, allowing access to memory faster than having to traverse the entire distance between the CPU and RAM. L1 (fastest, smallest, split into instruction and data) -> L2 (slower, bigger) -> L3 (slowest, biggest)

Pipelining

Pipelining allows the processor to execute each part of the fetch, decode execute simultaneously.

Words And Word Size

Each word is a group of bytes. When a processor wishes to read a word of data, the address is put on the bus. The width of the address bus determines the maximum possible amount of addressable words, where x is the width and \(2^x\) is the size.
The databus is similar, where the largest possible word transmittable is \(2^x-1\). See Maths Topic 1.1 - Index Laws for powers.

How This Relates To Assembly

Each instruction must fit into one word, which is split between opcodes (can only have \(2^x\) instructions with x opcode bits), addressing modes, operands, etc etc. (Machine code, assembled from assembly)
